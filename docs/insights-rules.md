# FitWell Journal — 洞察规则定义 v0.1

本文档是规则引擎的"规格说明书"。实现见 `backend/app/rules.py` 与 `backend/app/trends.py`，单元测试见 `backend/tests/`。

**总原则**：所有输出是启发式趋势洞察，不是医学结论。判断逻辑在规则引擎（可解释、可测试），任何 LLM 仅负责把结论写成人话。

## 1. 代谢规律分（metabolic score，0–100）

按自然日聚合，对每个有效日计算 4 个因子分，加权平均后取近 7 个有效日的均值。

| 因子 | 权重 | 打分规则 |
|---|---|---|
| 进食窗口时长（最早餐→最晚餐） | 0.35 | 8–10h：100；7–8h 或 10–11h：75；6–7h 或 11–12h：55；其余 35 |
| 末餐-入睡间隔 | 0.30 | ≥120min：100；60–120min：70；30–60min：45；<30min（含饭后即睡/夜宵）：25 |
| 进食节奏（当日餐次+加餐次数） | 0.20 | 3–5 次：100；2 或 6 次：70；其余 45 |
| 睡前 2h 进食 | 0.15 | 无：100；有：30 |

等级：≥85 A，≥70 B，≥55 C，其余 D。

## 2. 睡眠规律分（sleep score，0–100）

需要 ≥3 个有效睡眠日才出分，否则返回"数据不足"。

| 因子 | 权重 | 打分规则 |
|---|---|---|
| 睡眠时长 | 0.35 | 7–9h：100；6–7h 或 9–9.5h：75；5–6h 或 9.5–10h：50；其余 30 |
| 就寝时刻波动（圆形标准差） | 0.25 | ≤30min：100；≤60min：75；≤90min：50；其余 30 |
| 起床时刻波动 | 0.25 | 同上 |
| 社交时差（工作日 vs 周末就寝均值差） | 0.15 | ≤60min：100；≤120min：70；其余 40；样本不足（工作日<3 或 周末<2）给中性 70 并在 detail 注明 |

等级同上。

## 3. 趋势卡片（trend cards）

周环比（近 7 天 vs 前 7 天），变化超过阈值才生成卡片，方向词只用"上升/下降/基本持平"：

- 进食窗口均值变化 ≥ 30min
- 睡眠时长均值变化 ≥ 20min
- 体重变化 ≥ 0.5kg（数据点 ≥ 3/周）
- 压力均值变化 ≥ 0.5 分

措辞模板例：`近一周你的进食窗口平均缩短了 1.2 小时，方向良好`——只描述变化，不给医学结论。

## 4. 关联卡片（correlation cards）

组间对比，**任一组样本 < 3 天不生成卡片**（样本不足宁可不说）。每张卡片带 `evidence_days`。

| 卡片 | 对比 | 措辞模板 |
|---|---|---|
| 睡眠不足与加餐 | 前一天睡眠 <6h 的次日加餐次数 vs 其余次日 | "睡眠不足 6 小时的日子，次日加餐次数平均多 X 次（基于 N 天数据）" |
| 压力与睡前进食 | 压力 ≥4 的日子 vs ≤2 的日子，睡前 2h 进食发生率 | "压力较高的日子，睡前两小时进食的概率高出 X%" |
| 长进食窗口与次日精力 | 进食窗口 >11h vs 8–10h 的次日精力均值 | "进食窗口超过 11 小时后，次日精力评分平均低 X 分" |
| 训练与入睡时刻 | 训练日 vs 非训练日就寝时刻偏移均值 | "训练日你的入睡时间平均提前/推迟 X 分钟" |

红线检查：卡片生成函数的输出文案不允许出现"抵抗""诊断""患病""风险人群"等词（测试中断言）。

## 5. 周报响应结构

```json
{
  "period": { "start": "YYYY-MM-DD", "end": "YYYY-MM-DD" },
  "metabolic": { "score": 78, "grade": "B", "factors": [ { "name": "进食窗口时长", "score": 85, "weight": 0.35, "detail": "…" } ] },
  "sleep":     { "score": 71, "grade": "B", "factors": [ … ] },
  "cards":     [ { "kind": "trend|correlation", "title": "…", "detail": "…", "evidence_days": 12, "direction": "up|down|flat" } ],
  "series":    { "dates": ["…"], "eating_window_h": [9.5], "sleep_duration_h": [7.2], "bed_offset_min": [195], "weight_kg": [70.2], "stress": [3], "energy": [4] }
}
```

分数为 `null` 且 grade 为 `null` 表示数据不足，前端展示"数据不足，继续记录"。
